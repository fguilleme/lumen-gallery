# Screenshot provenance / Origine des captures

[English README](../../README.md) · [README français](../../README.fr.md)

## English

These are real Chromium screenshots of the unmodified LUMEN interface, captured against an isolated demo instance bound to loopback. They are not UI mockups and do not use a private photo library.

The sample library contains 45 derived JPEGs made from the 12 Unsplash images below. Mild exposure variations illustrate burst/near-duplicate groups. Camera names, dates, exposure settings and ratings are demonstration metadata, not the original photographers’ EXIF. All sample files were really indexed; both grouping modes were actually computed locally. No API responses or group assignments were fabricated.

The mobile image uses Chromium touch-device emulation, not a claim of Safari/iPhone validation. Screenshots are compressed WebP files; private libraries, source photographs, model weights, databases and generated secrets are not included in the repository.

Photographs are used under the [Unsplash License](https://unsplash.com/license). The links below record the actual source images. This attribution does not change the applicable image license.

## Français

Ces captures montrent la véritable interface LUMEN, dans Chromium, avec une instance de démonstration séparée écoutant uniquement en local. Ce ne sont pas des maquettes ; aucune bibliothèque photographique privée n’a été utilisée.

Les 45 JPEG de démonstration proviennent des 12 images Unsplash ci-dessous. De légères variations d’exposition illustrent les rafales et les photos proches. Les noms d’appareils, dates, réglages et notes sont des données de démonstration, pas les EXIF des photographes. Les fichiers ont réellement été indexés et les deux analyses de similarité réellement calculées en local, sans réponses d’API ni groupes simulés.

La capture mobile utilise l’émulation tactile de Chromium, sans prétendre valider Safari ou un iPhone réel. Seules les captures WebP sont suivies par Git : ni bibliothèque privée, ni photos sources, ni modèles, bases de données ou secrets générés.

Les photographies sont utilisées selon la [licence Unsplash](https://unsplash.com/license). Les liens ci-dessous identifient les images effectivement utilisées et ne remplacent pas leur licence.
